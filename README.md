# 네이버 & 쿠팡 가격 모니터링 독립 애플리케이션 (Naver & Coupang Price Monitor)

이 프로젝트는 네이버 쇼핑 및 쿠팡의 경쟁 상품 가격을 매일 추적하고, 최저가 차액 분석 및 Gemini AI 가격 추출 기능을 제공하는 전용 단독 애플리케이션입니다.

## 🚀 주요 기능
- **실시간 가격 비교 테이블**: 네이버 vs 쿠팡의 판매가, 배송비, 합계 금액 및 최저가 총액 하이라이트
- **Gemini 3.5 Flash AI 가격 파서**: 상품 페이지 텍스트 복사/붙여넣기 또는 화면 캡처 이미지 붙여넣기로 판매가 및 배송비 자동 추출
- **가격 변동 추세 차트**: 일별 최저가 변화를 한눈에 파악할 수 있는 시각화 차트
- **데이터 보존 및 동적 관리**: LocalStorage + Supabase 동기화, JSON 백업 추출 및 복구 기능

## 💻 실행 방법
```bash
# 1. 패키지 설치
npm install

# 2. 개발 서버 실행
npm run dev

# 3. 빌드 및 타입 검사
npm run build
```
